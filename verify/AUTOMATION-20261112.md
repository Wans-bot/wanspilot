# WansPilot 1.4.0 验收记录

时间：2026-11-12，Asia/Shanghai。基线：1.3.0 / 119e004。

## 本轮交付

- 批量订阅检查、暂停、启用与自动下载开关；搜索/状态筛选/排序与明确选择。
- 独立字面关键词、编码、体积、严格画质、每季集号范围、检查间隔；范围限制同步到日历缺集统计。
- 逐集管理：有效季及 TMDB 集号验证、50 集分页、手动已下载/恢复待补记录，运行中或已提交任务的记录冲突返回 409。
- 下载筛选及批量暂停/继续，逐项反馈；不提供批量删除文件。
- 持久化站内通知（300 条、已读、10 分钟重复合并）与运行总览；铃铛轮询时同步订阅下载完成状态。
- 固定上海时间：UI、日历日界、检查计划文案、新日志和订阅导出。内部绝对时刻继续使用 ISO UTC，历史日志原样保留。
- 新增界面沿用中性面板、留白和图标，无装饰性彩色边条。

- `npm --prefix content run check`：入口及新增模块语法检查通过。

测试使用临时独立后端与本地 mock qB/TMDB/资源，不会登录或修改 NAS，也不提交真实下载。未更改用户 NAS 生产部署；Compose 保持 latest、TZ、账号密码，无 PUID/PGID。

## 限制

本轮实现核心管理功能，不宣称覆盖 MoviePilot 全部插件、站点认证或媒体服务器通知集成。逐集标记仅维护记录，不校验磁盘文件；播出日期来自 TMDB，不代表精确播出时刻。实际下载仍需有效 TMDB、可用资源来源、qB 连接及匹配规则。
