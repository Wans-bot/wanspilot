# WansPilot 1.2.0 前端整体打磨

日期：2026-11-12

## 范围

统一 cinema.css 中的组件设计与 mobile.css 中的移动布局，没有新增覆盖样式文件。首页减少重复入口；搜索使用常用条件与折叠高级条件；下载任务桌面对齐、手机卡片；订阅补充实际下载/已播集数与本月日历日期；设置高级字段折叠、连接与保存状态就地反馈。登录、详情、资源和日历沿用同一套中性色面、字号、圆角与间距。

禁止装饰性彩色边条。下载进度与可访问焦点属于功能性指示，保留。订阅日期只取日历接口，未知与接口失败不生成假日期。图片按 w780/w1280 响应式请求，海报失败提供图标占位。移除搜索跨页补齐行为，避免下一页作品在当前页重复出现。

## 验证

- `npm test --prefix content`：53 项通过。
- `npm run check --prefix content`：通过。
- `git diff --check`：通过。
- `WP_MOBILE_MATRIX=1 WP_SCREENSHOTS=/tmp/wp-refine-final node verify/browser-smoke.mjs`：61 项浏览器检查；深浅主题 × 7 个视口 × 13 页面，共 182 组布局检查。
- 新增真实浏览器操作：筛选与重置、qB 连接成功/失败、TMDB 与图片源结果独立、任务暂停/继续及可访问进度、手机进度条可见、订阅下载计数去重与已知/未知日期、背景图 srcset 与海报错误占位。
- 人工检查桌面、手机、浅色主题截图，包括展开的网络设置、搜索、订阅、任务、详情和登录。

测试使用独立临时服务与模拟 API；截图的海报为测试占位，未宣称访问生产影视数据。未操作 NAS 数据、生产下载或生产容器；qB 历史版本兼容仍以现有协议模拟回归为基础。

## 发布与部署

版本 1.2.0，提交后由 main 工作流发布 GHCR `latest` 与提交 SHA 标签，支持 amd64、arm64。具体运行状态与镜像摘要由发布后核验记录，不在此预先声明成功。

原有 NAS YAML 无须改变。保留现有账号密码、`./data` 和视频目录，更新时拉取并重建容器；单纯重启不会更新镜像。
