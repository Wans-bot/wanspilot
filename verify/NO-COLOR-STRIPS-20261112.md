# WansPilot 1.1.3 去除彩色边条

用户要求 WansPilot 移除所有装饰性彩色边条，并作为全部项目的长期设计约束。

- 日历任务卡片取消左侧状态色条，保留中性细边框和已有状态文字 / 圆点。
- 设置导航选中项取消彩色 inset 边条，选中状态由文字、浅底色表达。
- 首页取消精选标题前装饰短线，轮播切换指示改成中性圆点。
- 提示、状态面板与日历今天标记改用中性边框；清理旧版彩色框线与底部渐变状态条规则。
- `AGENTS.md` 记录此设计约束；不使用单侧彩色边框、标题色条或模拟边条的内阴影。功能性进度和无障碍焦点指示保留。

验证：`npm run check --prefix content`、`git diff --check` 通过；53 项后端测试通过。现有浏览器套件 54 项通过，双主题 7 视口 13 页面共 182 组合检查无布局异常。人工检查桌面月历、手机时间线、桌面设置和首页截图，确认彩色边条移除。模拟媒体和任务不代表 NAS 生产库。

截图与机器结果保存在 `verify/no-color-strips/`。未修改 NAS 生产容器或下载任务。
