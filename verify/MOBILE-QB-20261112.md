# WansPilot 1.1.2 手机适配与 qB 兼容验收

## 改动范围

- 统一 860px 手机 / 平板断点与底部导航尺寸，适配安全区域、横屏及窄屏。
- 搜索 / 资源筛选在手机可折叠，在桌面完整展开，跨断点切换同步 disclosure 状态。
- 详情海报和片名并排，首页、任务统计、资源和订阅卡片采用紧凑手机布局；修复浅色详情的文字对比度。
- 手机设置改为原生分区选择，切换保留输入草稿。保存区改为随表单滚动，页面实际内容底部预留导航空间，避免固定高度 body 的 padding 无法保护溢出内容。
- 弹窗锁定背景滚动、设置 inert、约束键盘焦点，跟随 visualViewport；关闭后恢复焦点和操作。路由改变或认证失效时清理弹窗。
- qB 自动探测 v2 / legacy，只使用读取接口探测。4.x 使用 pause/resume，5.x 使用 stop/start；只有接口缺失时尝试备用命令并缓存。
- 旧版磁力 / 文件分别使用 download / upload，暂停恢复使用单 hash，删除支持 delete/deletePerm。API6 及更早磁力使用表单编码，API13 前拒绝暂停添加，避免静默忽略用户意图。
- 兼容会话 cookie 名称、200 / 204 登录响应、401 / 403 认证挑战与免认证访问；带目标 Origin / Referer。添加失败不会改接口重放；认证或服务错误不作为版本降级依据。
- 可选磁盘统计缺失时不阻止核心任务连接，未知空间不显示为 0，真正的 0 保留。

## 参考

- MoviePilot-Frontend v3 的 `src/layouts/components/Footer.vue`、`src/layouts/DefaultLayout.vue`：参考移动导航、内容留白与断点一致性的思路，WansPilot 独立实现。
- qBittorrent 官方 wiki：`WebUI-API-(qBittorrent-v3.2.0-v4.0.4).md`、`WebUI-API-(qBittorrent-5.0).md`。按协议适配，没有引入第三方客户端依赖。

## 验证

- `npm test --prefix content`：53 项通过，新增 16 项 qB 协议回归。
- qB 使用独立 HTTP 模拟服务，覆盖 4.1.9 / 4.3.9 / 4.6.7 / 5.0.3 / 5.1.2、legacy 4.0.4 / 3.3.16 / 3.2.0，以及 API6 / 7 / 12 边界；不是这些版本逐一实机安装验收。
- `npm run check --prefix content`、`git diff --check`：通过。
- `WP_MOBILE_MATRIX=1 WP_SCREENSHOTS=verify/mobile-v1 node verify/browser-smoke.mjs`：54 项浏览器检查，矩阵包含 2 主题 × 7 视口 × 13 页面，共 182 组。检查横向溢出、输入裁切、顶栏控件重叠、底部导航位置和设置保存区可达性。
- 视口：320×740、360×780、390×844、430×932、768×1024、844×390、1024×768。另有 390×430 短弹窗测试、筛选展开 / 跨断点、设置草稿、弹窗焦点及登录检查。
- 截图与机器结果保存在 `verify/mobile-v1/`。媒体、海报与任务均为验收样例；不代表生产库。

未修改 NAS 生产配置或下载任务。手机测试使用 Chromium 视口模拟，尚未逐台验证 iOS Safari / Android 实机键盘。旧 API 有能力限制，无法保证所有历史或非官方修改版本。
